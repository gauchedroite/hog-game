# Hog

A small two-player dice game built with plain HTML, CSS, and TypeScript. First player to bank 100 points wins. Rolling a 1 ends your turn and clears the points you built that turn.

## Run it

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:8123`.

The dev command rebuilds TypeScript when files change and starts the static server without caching, so press Ctrl+R after a build finishes.

Run the game logic tests with `npm test`.
